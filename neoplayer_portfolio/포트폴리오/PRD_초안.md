# PRD 초안: 기획자의 커뮤니티 담당자

> 작성일: 2026-11-23 · 상태: 초안 (문답으로 계속 다듬는 중)
> 구조: 4MAT (Why → What → How → What if)

---

## 1. Why — 배경과 문제

흩어진 대량의 유저 의견을 다 읽을 수 없어서, 언제 무엇부터 고칠지 근거가 없다.

---

## 2. What — 컨셉

**기획자의 커뮤니티 담당자**
읽고 정리해서 개선 로드맵의 근거를 만든다.

---

## 3. How — 구현 방법

### 처리 단계
수집 → 정제 → 분류 → 집계 → 출력

### 멀티에이전트 구조

| 에이전트 | 하는 일 |
|---|---|
| 오케스트레이터 | 전체 순서를 관리하고 결과를 합침 |
| 수집 에이전트 | Aside로 커뮤니티와 업데이트 공지 수집 |
| 분류 에이전트 | 시스템 영역 8개로 분류하고 심각도 판단 |
| 검증 에이전트 | 분류 결과를 보지 않고 독립적으로 다시 분류한 뒤 비교 (독립 재분류형) |
| 요약 에이전트 | 영역별 부정 글에서 반복되는 문제를 한 문장으로 뽑고, 근거 글이 많은 순으로 TOP 5 정리 |
| 설문 에이전트 (발전 가능성) | 인게임 설문 서술형 정리 |

- 재검토 흐름: 검증 에이전트가 틀린 분류를 찾으면 오케스트레이터가 해당 글을 분류 에이전트에게 다시 보냄 (1회). 그래도 다르면 '담당자 검수'로 표시

### 분류 기준: 시스템 영역 8개
1. 재도전·실패 규칙
2. 횟수·주기·초기화
3. 모험단 구조
4. 동행(APC) 규칙
5. 재화·경매 규칙
6. 해금·단계 구조
7. 피로도 소모 방식
8. 컨텐츠 역할·엔드 컨텐츠

### 우선순위 기준
| 기준 | 판단 주체 |
|---|---|
| 빈도 | 에이전트 |
| 심각도 | 에이전트 |
| 개발 비용 | 사람 (기획자·개발팀) |
| 타이밍 | 사람 (기획자) |

### 최종 결과물
- Claude 아티팩트로 만든 사이트: Aside가 수집한 데이터를 정리하고 시각화해서 보여줌

| 보는 사람 | 결과물 |
|---|---|
| 기획팀 | 상세 표 |
| 개발팀 | 우선순위 표 |
| 리더 | 한 장 요약 |

### MVP 범위
- 데이터: 커뮤니티 데이터만 사용
- 정제(광고·도배·중복·무관한 글 제거): MVP에서는 Aside 수집 단계에서 무관한 글을 거름. 정제 에이전트는 발전 가능성
- 도구: Aside(수집), Claude 아티팩트 사이트(업로드·분류·검증·시각화), Python(일치율 계산 등 검증용)

## 4. What if — 기대 효과와 성공 지표

### 기대 효과
- 지금: 매번 2~3시간
- 이후: 매주 자동 실행하고 검토만

### 성공 지표 (합격선)

| 지표 | 합격선 |
|---|---|
| 분류 일치율 | 80% |
| 반복 문제 탐지 | TOP 5 중 4개 |
| 원문 링크 | 100% |

### 측정 결과 (최종 v0.3.1)

| 지표 | 합격선 | 결과 |
|---|---|---|
| 분류 일치율 | 80% | 기존 135개 87.4%, 신규 30개 86.7% → 달성 |
| 반복 문제 탐지 | TOP 5 중 4개 | 3/5 (v0.5, 미달) |
| 원문 링크 | 100% | 140개 모두 → 달성 |

- 반복 문제 탐지 판정 기준: 같은 레이드·규칙에 대한 불만이라도 유저가 겪는 불편이 다르면 다른 문제로 봄 (판정: 사용자)
- 미달 원인 1: 근거 글 수만으로 순위를 매겨, 찾아낸 문제(실패 시 횟수 차감)가 9위로 밀림
- 미달 원인 2: 관련 글이 다른 영역으로 분류돼 요약 대상에 들어가지 못함(여러 캐릭터 육성 부담)
- 개선(다음 버전): 순위 기준에 심각도 반영, 영역당 1개 제한 → 새 데이터로 검증

### 버전 기록
- 1차 79.3% → 2차 85.9% → v0.3.1 87.4% (신규 86.7%) → v0.4 91.9% (신규 83.3%, 기존 데이터에만 맞춘 개선이라 미채택)

### 발전 가능성
| 내용 | 연결 |
|---|---|
| 중국 커뮤니티 수집 + 중국 게임 은어·줄임말·고유명사 번역 | 니즈 2 |
| 정제 단계에서 비속어 처리 | 니즈 1 |
| 설문 에이전트로 인게임 설문 서술형 분류·정리 | 여정 지도 4단계 |
