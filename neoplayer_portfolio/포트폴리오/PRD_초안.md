# PRD 초안: 기획자의 커뮤니티 담당자

> 작성일: 2026-11-23 · 상태: 초안 (문답으로 계속 다듬는 중)
> 구조: 4MAT (Why → What → How → What if)

---

## 1. Why — 배경과 문제

흩어진 대량의 유저 의견을 다 읽을 수 없어서, 언제 무엇부터 고칠지 근거가 없다.

---

## 2. What — 컨셉

**기획자의 커뮤니티 담당자**
읽고 정리해서 개선 로드맵의 근거를 만든다.

---

## 3. How — 구현 방법

### 처리 단계
수집 → 정제 → 분류 → 집계 → 출력

### 멀티에이전트 구조

| 에이전트 | 하는 일 |
|---|---|
| 오케스트레이터 | 전체 순서를 관리하고 결과를 합침 |
| 수집 에이전트 | Aside로 커뮤니티와 업데이트 공지 수집 |
| 분류 에이전트 | 시스템 영역 8개로 분류하고 심각도 판단 |
| 검증 에이전트 | 분류가 원문과 맞는지 다시 확인 |
| 설문 에이전트 (2단계) | 인게임 설문 서술형 정리 |

### MVP 범위
- 데이터: 커뮤니티 데이터만 사용
- 도구: Aside, Python, Claude API

---

## 4. What if — 기대 효과와 성공 지표

### 기대 효과
- 지금: 매번 2~3시간
- 이후: 매주 자동 실행하고 검토만

### 성공 지표 (합격선)

| 지표 | 합격선 |
|---|---|
| 분류 일치율 | 80% |
| 반복 문제 탐지 | TOP 5 중 4개 |
| 원문 링크 | 100% |

---

## 5. 하지 않을 것 (Non-goals)

- 최종 우선순위 결정은 하지 않음 (기획자와 개발팀이 결정)
