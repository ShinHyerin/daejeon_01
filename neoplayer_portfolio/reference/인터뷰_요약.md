# 현업 인터뷰 요약 (공고 첨부)
※ '제주' 근무 관련 내용은 무시 (서울 지원).

## 1. 모바일 던파 던전 컨텐츠 기획 — 컨텐츠2팀 팀장 (가장 중요)
- 경력: PC 던파 유저 출신, 네오플 12년. PC 던파 던전팀(몬스터·던전 → 레이드·대규모 업데이트) → 모바일 던파.
- 팀의 일: 모험가가 던전에서 느낄 재미를 설계. 던전 하나가 아니라 모바일 던파 세계 안에서 각 던전의 역할과 새로운 플레이 경험까지 함께 그림.
- 모바일 던파만의 기획:
  - PC 세계관·재미를 이어받되 완전히 다른 환경에서 새로 만드는 게임.
  - 조작 차이: 키보드로 쉽게 피하던 패턴도 터치로는 버거움 → **패턴 예고 시간·판정 범위**를 모바일에 맞게 재조정.
  - 플레이 방식: 이동 중·잠깐 쉬는 시간 접속 → **던전 한 판의 길이, 하루 컨텐츠 흐름**을 모바일 생활 패턴에 맞춤.
  - 핵심: PC 던파의 손맛은 지키면서 모바일만의 편안함을 더하는 것.
  - 계속 성장하는 게임, 시즌마다 새 시도 → 레이드 구조·던전 방식처럼 '처음 만드는 일'에 참여 가능.
- 레벨업 순간: PC 노하우가 모바일에서 안 통함 → **'익숙한 답'을 의심하는 법**을 배움.
- 인턴 업무: 1~2개월 기존 던전·레이드 기획서, 스크립트 데이터 학습(팀 가이드 + 사수) → 몬스터 패턴/던전 일부를 맡아 기획서 작성 + 데이터 제작, 사수와 리뷰 → 실제 게임 반영 가능.
- 기대 역량:
  - **'왜?'에 끝까지 답하는 힘** — 리뷰에서 "이건 왜 여기 들어가야 해요?"가 반드시 나옴. '재밌을 것 같아서'가 아니라 어떤 경험을 원하고 패턴이 그걸 어떻게 만드는지 설명.
  - **구현 가능한 말로 바꾸는 힘** — "보스가 화나면 강해진다" → "체력이 절반 이하로 떨어지면 공격이 빨라지고 패턴 순서가 바뀐다".
- 분위기: 연차 무관 편하게 묻고 답하는 문화, 선배들의 던전 제작 노하우. 서울 사무실 교통 편리.
- 한마디: 방대한 데이터·낯선 용어에 막막해도 물어보면 됨. 던파 애정 + "어떻게 더 재밌게 만들까" 고민. 내가 만든 패턴의 공략 영상이 올라오는 짜릿함.

## 2. PC 던파 — 컨텐츠 / 파밍·시스템 / 이벤트·유료화 기획
- 컨텐츠: 던전·몬스터·레이드·이벤트. 자신을 **아키텍트**에 비유 — 모양뿐 아니라 공간과 쓰임, 즉 **맥락·편의·공평함**까지 설계하고 여러 직군과 구체화.
- 파밍/시스템: **'거대한 퍼즐'** — 파밍/캐릭터/컨텐츠/라이브로 조각을 나누는데 모서리가 어긋날 수 있음 → 내 조각이 어디서 맞닿는지 미리 살핌.
- 이벤트/유료화: '버전의 리듬'을 설계 — 큰 업데이트 땐 몰입을 돕고, 쉬어 가는 시기엔 빈자리를 채움.
- 오래된 게임에 새 기획: 레거시 존중, 과거 컨텐츠와의 상호작용, 오랜 유저 반응 고려. 섣불리 손대면 예상 못 한 문제.
- 인턴: 기존 컨텐츠 재기획·개선 기획 → 실제 반영. 기존 기획서 분석·발표. 장비·보상 구조를 보며 '왜 이렇게 만들었을까' 고민 → 기획서로 제안.
- 기대: 애정 + 전체를 보는 균형 + 논리 + 설득 커뮤니케이션. "왜 이렇게 만들었을까", "나라면 어떻게 고칠까"를 고민해 본 경험. **자기 역량을 이해하고 이 직무에 어떻게 쓸지 고민한 사람.**
- 인용: '게임의 목적은 새로운 경험으로 사람들을 놀라게 하고 즐겁게 하는 것'.

## 3. 던전앤파이터 클래식 — 컨텐츠 기획 (참고)
- 사이클: 문서 설계 → 직접 제작 → 플레이 → 수정. 테스트 이슈 예: "이 몬스터 패턴은 피할 틈이 없다", "이 방은 너무 길다".
- 원작을 그대로 옮기지 않고 몬스터 배치·패턴 템포를 지금 유저 기준으로 재조정. 흐름에 안 맞으면 과감히 뺌. 로드맵 전체(출시/다음 시즌)를 함께 그림.
- 성장 사례: 레벨업 구간 문제 발견 → 예전 경험치 던전 참고해 신규 던전 기획·제안 → 반영. "문제를 먼저 발견하고, 해결책을 만들고, 끝까지 밀고 가는 기획자".
- 기대 역량 질문: **"최근 한 게임에서 불편했던 점, 내가 기획자라면 어떻게 고칠지"** — 관찰력("이 보상은 왜 이 주기로 줄까?") + 근거로 설득("여기서 유저가 이탈하니까 이게 필요하다").
- 직접 만들어 보고 수치를 바꿔 반복하는 걸 귀찮아하지 않기. 추억에만 기대지 않는 냉정한 균형 감각.
- 목표: **숫자와 손맛을 둘 다 잡는 기획자.**
- 문화: 근거만 있으면 반대 의견 OK, "말보다 플레이로 이야기", 결정은 문서로 남김.
