# archive.csv 기록 규칙

경쟁 광고·콘텐츠 아카이브(`archive.csv`)를 채우는 규칙이다.
이 폴더의 `CLAUDE.md` 규칙 2번("아카이브에 없는 광고는 인용하지 않는다")에 따라, **기획서·카피에서 실제 광고를 인용할 때는 이 파일에 있는 행만 쓴다.**

## 기본 원칙

1. **1건 = 1행.** 같은 광고의 다른 버전은 행을 나누지 않고 `변형 수`에 센다. 내용(훅·메시지)이 다르면 다른 건으로 본다.
2. **직접 보고 확인한 것만 적는다.** 지어내거나 기억으로 채우지 않는다. 직접 만든 시안은 이 파일에 넣지 않는다.
3. **모르는 칸은 `[확인 필요]`로 둔다.** 빈칸으로 두지 않는다. (빈칸은 "아직 안 봄"과 "봤는데 없음"이 구분되지 않는다.)
4. **원문은 원문대로.** `훅 문장 원문`은 고치거나 요약하지 않는다. 해석은 `핵심 메시지`와 `우리 적용 아이디어`에 쓴다.
5. **날짜는 `YYYY-MM-DD`** 형식으로 쓴다.
6. **선택지가 있는 칸**은 아래 선택지의 말을 그대로 쓴다. 맞는 것이 없으면 `기타: (설명)`으로 쓴다.
7. 파일은 UTF-8로 저장되어 있다. 엑셀에서 수정한 뒤에는 "CSV UTF-8"로 저장한다.

## 칸별 기록 방법

| # | 칸 | 기록 방법 | 예시 형식 |
|---|---|---|---|
| 1 | 번호 | 1부터 순서대로. 지운 번호는 다시 쓰지 않는다 | `1`, `2`, `3` |
| 2 | 수집일 | 내가 이 광고를 보고 기록한 날 | `2026-11-13` |
| 3 | 브랜드 | 광고한 게임·브랜드 이름. `benchmark_후보.md`의 표기와 맞춘다 | `몬길: 스타 다이브`, `명조: 워더링 웨이브` |
| 4 | 채널 | 어디서 봤는지. 플랫폼 이름으로 쓴다 | 유튜브, 유튜브 쇼츠, 인스타그램, X, 틱톡, 앱스토어, 구글플레이, 공식 사이트, 커뮤니티(채널명) |
| 5 | 유형 | 선택지에서 하나 (아래) | `광고` |
| 6 | 링크 | 원본 주소. 광고 라이브러리에서 찾았으면 그 주소 | `https://...` |
| 7 | 캡처 파일명 | 캡처 이미지·영상 파일 이름. 광고는 내려가면 사라지므로 **반드시 캡처**한다. 이름 규칙은 아래 제안을 따르거나 정해서 바꾼다 | `001_명조_유튜브_20261113.png` (제안) |
| 8 | 게재 시작일 | 게시일 또는 광고 라이브러리의 게재 시작일. 확인할 수 없으면 `[확인 필요]` | `2026-11-01` |
| 9 | 게재 기간(일) | 수집일 − 게재 시작일. 아직 게재 중이면 숫자 뒤에 `(게재 중)` | `12 (게재 중)` |
| 10 | 포맷·길이 | 형식과 길이 | `세로 영상 15초`, `가로 영상 2분 30초`, `이미지 1장`, `캐러셀 5장`, `스토어 페이지` |
| 11 | 첫 3초 훅 유형 | 선택지에서 **가장 강한 하나** (아래) | `반전` |
| 12 | 훅 문장 원문 | 첫 3초의 자막·대사·문구를 그대로. 말이 없으면 화면을 한 줄로 묘사하고 앞에 `(화면)`을 붙인다 | `"..."` 또는 `(화면) 캐릭터가 ...` |
| 13 | 핵심 메시지 | 이 콘텐츠가 결국 하려는 말을 내 말로 한 문장 | `늦게 시작해도 따라잡을 수 있다` |
| 14 | 근거 유형 | 선택지에서. 여러 개면 `; `로 구분. 근거가 없으면 `없음` | `수치; 후기` |
| 15 | 오퍼 | 보는 사람에게 주는 혜택. 보상 이름과 수량을 화면에 나온 그대로. 없으면 `없음` | `신규 접속 시 ... 지급` |
| 16 | CTA | 행동을 요구하는 문구 원문. 없으면 `없음` | `지금 다운로드` |
| 17 | 고객여정 단계 | 선택지에서 **주로 노리는 하나** (아래) | `비교·의심` |
| 18 | 톤·비주얼 | 분위기와 화면 특징을 짧게 | `밝음, 캐릭터 클로즈업, 빠른 컷` |
| 19 | 댓글 주요 반응 | 많이 보이는 반응 2~3개를 요약하고, 대표 댓글은 따옴표로 원문 인용. 댓글이 없거나 닫혀 있으면 `댓글 없음` | `복귀 고민 많음; "..."` |
| 20 | 변형 수 | 같은 광고의 다른 버전(길이·자막·썸네일만 다른 것) 수. 하나뿐이면 `1` | `3` |
| 21 | 우리 적용 아이디어 | 몬길에 어떻게 쓸지 한 줄. 아이디어는 직접 만든 것이므로 여기만 내 의견 | `3단계에서 신규 지급 수량을 숫자로 먼저 보여주기` |

## 선택지

### 유형
| 선택지 | 기준 |
|---|---|
| 광고 | 돈을 내고 노출한 콘텐츠 (광고 표시, 스폰서, 광고 라이브러리에 있음) |
| 오가닉 | 공식 계정이 광고비 없이 올린 게시물·영상 |
| 작품 | 크리에이터·스트리머·유저가 만든 콘텐츠 (공략, 플레이 영상, 팬아트 등). 협찬 표시가 있으면 `톤·비주얼`에 `협찬` 표기 |
| 굿즈 소개 페이지 | 굿즈·스토어·이벤트 소개 페이지 (스토어 페이지, 공식 이벤트 페이지, 팝업 소개 페이지 포함) |

### 첫 3초 훅 유형
| 선택지 | 기준 |
|---|---|
| 문제 공감 | 고객의 불편·고민을 먼저 말한다 |
| 반전 | 예상을 깨는 장면이나 말로 시작한다 |
| 질문 | 보는 사람에게 질문을 던진다 |
| 결과 먼저 | 결과(획득 장면, 완성된 파티, 보상 화면 등)를 먼저 보여준다 |
| 감각(소리·질감·사용 장면) | 소리, 타격감, 실제 플레이 장면처럼 감각으로 끌어당긴다 |
| 인물 | 캐릭터·성우·크리에이터 등 인물이 전면에 나온다 |

### 근거 유형
| 선택지 | 기준 (게임에서는) |
|---|---|
| 성분·사양 | 사양·구성: 캐릭터 성능, 시스템 설명, 지급 내용, 확률·확정 구조 |
| 수치 | 숫자로 말함: 다운로드 수, 순위, 보상 수량, 기간 |
| 후기 | 실제 유저의 말·평점·인증 |
| 전문가 | 크리에이터·스트리머·개발자·매체의 평가 |
| 비교 | 다른 게임이나 이전 버전과 비교 |
| 인증 | 수상, 스토어 추천, 등급·심의 같은 제3자 인정 |
