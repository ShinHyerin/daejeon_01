# 검토용 초안 보관: 맥 스튜디오 코드어시스턴트

작성·수정일: 2026-11-03. 같은 프로젝트 대화의 최신 초안을 그대로 보관했다. 사용자 최종 승인·네이버 게시를 완료한 문서가 아니며, 이번 보관 작업에서는 기사 원문을 새로 재검증하거나 본문을 수정하지 않았다. 본문의 굵은 문장 2곳은 형광펜 적용 대상이다.

---

**유라클, 맥 스튜디오 기반 AI 코딩 솔루션 공급 확대 추진**

AI 코딩 도구를 도입할 때는 개발 기능뿐 아니라 소스코드를 어디에서 처리하는지도 살펴봐야 합니다. 회사 코드를 외부로 보내는 것이 부담스럽고, 별도 AI 서버를 구축하기도 어려운 조직이라면 도입 방식부터 고민하게 됩니다.

유라클은 이러한 기업을 대상으로 맥 스튜디오 기반 ‘아테나 코드어시스턴트’를 소개했습니다. 2026년 10월 30일 전자신문 보도에 따르면, 유라클은 같은 달 21~22일 열린 애플 파트너 행사에서 애플 공인 파트너들에게 솔루션을 선보였습니다.

**맥 스튜디오에서 AI 모델을 직접 실행해, 소스코드를 외부 클라우드로 전송하지 않고 코드 작성과 수정 등을 지원하는 구성입니다.**

회사에 따르면 맥 스튜디오의 통합 메모리를 활용해 별도 AI 서버 없이 언어모델을 실행합니다. 개발자는 기존 개발 도구에 플러그인을 연결하거나 명령줄 인터페이스(CLI)를 통해 사용할 수 있습니다.

기존 코드를 파악하는 업무도 지원합니다. 소스코드 구조를 분석하고 사내 문서를 검색해 답변을 생성하며, 관리자는 사용량과 팀별 이용 정책, 감사 기록을 확인할 수 있다고 설명했습니다. 로컬 모델을 기본으로 사용하되, 필요에 따라 외부 상용 AI 모델을 선택적으로 연동할 수도 있습니다.

**이번 공급 확대는 소스코드 보안과 서버 구축 부담으로 도입을 미뤄 온 기업에 내부 AI 코딩 환경을 제시하는 데 초점을 맞추고 있습니다.**

유라클은 애플 공인 파트너와 협력해 기업 고객 대상 공급을 확대할 계획이라고 밝혔습니다.

**핵심 요약**

- 맥 스튜디오에서 AI 모델을 실행하는 아테나 코드어시스턴트를 소개했습니다.
- 기존 개발 도구 연계와 코드 분석, 사내 문서 검색, 조직별 이용 관리를 지원합니다.
- 애플 공인 파트너와 함께 기업 고객 대상 공급 확대를 추진합니다.
