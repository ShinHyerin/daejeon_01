# 검토용 초안 보관: 오르다 API 게이트웨이

작성·수정일: 2026-11-03. 같은 프로젝트 대화의 최신 초안을 그대로 보관했다. 사용자 최종 승인·네이버 게시를 완료한 문서가 아니며, 이번 보관 작업에서는 기사 원문을 새로 재검증하거나 본문을 수정하지 않았다. 본문의 굵은 문장 2곳은 형광펜 적용 대상이다.

---

**유라클, AI 이용 권한과 비용 관리하는 ‘오르다 API 게이트웨이’ 출시 발표**

유라클이 기업의 AI 서비스 이용을 통합 관리하는 ‘오르다 API 게이트웨이(AURDA API Gateway)’ 출시를 발표했습니다. 2026년 11월 3일 디지털투데이 보도에 따르면, 기존 오르다를 두 제품으로 재편하고 GPU·NPU 자원 운영 기능은 ‘오르다 인프라’로 분리했습니다.

**오르다 API 게이트웨이는 외부 대규모언어모델(LLM)과 사내 AI 모델, AI 에이전트, MCP 서버를 하나의 접속 지점으로 연결하는 플랫폼입니다.**

회사에 따르면, 기반 모델의 버전이 바뀌거나 다른 모델로 교체될 때 서비스 수정 부담을 줄이도록 지원합니다. 요청이 대기하는 시점부터 답변이 생성될 때까지 처리 과정을 추적해, 응답 지연의 원인을 확인하는 기능도 제공합니다.

AI 이용 권한과 비용도 함께 관리합니다. 사용자와 서비스별로 이용할 수 있는 모델과 기능을 지정하고, 토큰 사용 한도와 조직·팀·서비스별 예산을 설정할 수 있습니다.

**누가 어떤 AI를 사용할 수 있는지 정하고, 조직별 이용 한도와 예산을 함께 관리하는 것이 주요 기능입니다.**

보안 관리 기능도 포함했습니다. 회사는 AI 입력과 출력에 보안 정책을 적용하고, 위험도가 높은 요청은 사람이 확인하고 승인한 뒤 실행하도록 설정할 수 있다고 설명했습니다. AI 이용 기록을 남기는 기능도 지원한다고 밝혔습니다.

**핵심 요약**

- 유라클이 오르다 API 게이트웨이 출시를 발표하고, 기존 자원 운영 기능은 오르다 인프라로 분리했습니다.
- 여러 AI 모델과 에이전트를 연결하고, 이용 권한·토큰 한도·조직별 예산을 관리합니다.
- 요청 처리 과정 추적과 보안 정책 적용, 위험 요청에 대한 사람의 승인을 지원한다고 설명했습니다.
