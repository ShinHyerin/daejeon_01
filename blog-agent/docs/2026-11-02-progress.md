## 2. 주제 검토와 방향 정리

목표는 관심 기업 또는 경쟁사의 공개 자료를 모아 상품과 마케팅을 분석하고, 기업에 필요한 블로그 콘텐츠를 만드는 자동화 프로젝트다. 마케팅 PM 또는 개발 PM 이직을 위한 과제·포트폴리오 맥락에서 검토했다.

처음에는 게임회사를 검토했다. 사용자가 말한 콘텐츠 채널에는 블로그뿐 아니라 유튜브, 네이버 라운지, 카페도 포함된다. 게임회사는 업데이트·캐릭터 정보를 이미 제공하므로 채널의 유무만으로 자동화 필요성을 설명하기 어렵다는 점을 정리했다. 개인의 게임 분석 블로그가 과제의 목적은 아니라는 점도 바로잡았다.

이후 오미아코리아 등 제조업 후보와 송원산업·국도화학·삼양이노켐·동진쎄미켐을 검토했다. 사용자가 제조업에 익숙하지 않다고 설명하면서 유라클을 제안했고, 후속 자료 수집은 유라클에 집중했다. 제조업 후보는 탐색 과정이며 최종 조사 대상과 구분한다.

유라클에는 이미 공식 블로그가 있다. 따라서 현재 방향은 기존 상품·기술 자료를 활용해 고객이 이해하기 쉬운 콘텐츠를 지속적으로 만드는 것이다. Athena를 중심으로 시작하자는 제안과 첫 글 후보인 “기업용 AI 에이전트, 일반 챗봇과 무엇이 다르고 어떤 업무에 쓸까?”가 나왔지만, 최종 제품 범위와 글 주제는 아직 확정하지 않았다.

## 4. 경쟁사 콘텐츠 벤치마킹

투비소프트와 인스웨이브는 기업용 개발 플랫폼 분야의 콘텐츠 참고 대상으로 삼았다. 유라클의 모든 사업에서 직접 경쟁한다는 의미는 아니다.

회사별로 기사·성과, 사례, 기술·트렌드, 행사 유형의 게시물 4개씩을 골라 캡처했다. 각 게시물에 원문과 발행일, 화면에서 관찰한 편집 방식, 유라클 적용 방법, 바꿀 점을 기록했다.

| 회사 | 관찰한 구성 | 유라클 적용 시 참고할 점 |
| --- | --- | --- |
| 투비소프트 | 소제목과 굵은 문장, 요약 카드·비교 도식, 고객 문제부터 전환 과정을 설명하는 사례, 현장 사진과 설명, 일부 글의 문의·데모 배너 | 사실 요약과 소제목을 활용하고, 문제 → 적용 방식 → 확인된 변화 순서로 구성 |
| 인스웨이브 | 브랜드 표지, 형광펜 강조, 관련 기사 카드, 질문형 소제목·카드형 기술 설명, 문의·뉴스레터 배너 | 강조할 사실과 고객 이익을 먼저 고르고 관련 제품·문의로 연결 |

적용 아이디어는 네 가지다. 기사형은 핵심 요약 → 필요한 문장 강조 → 제품·문의 링크, 사례형은 고객 문제 → 적용 상품과 방식 → 결과 또는 진행 상태 → 상담 안내, 기술형은 독자의 질문 → 한 장 설명 → 실무 예시 → 상품 활용 범위, 행사형은 현장 사진 → 시연·질문 → 고객에게 주는 의미 → 다음 행동 안내로 구성한다. 이는 기획 제안이며 자동화 템플릿으로 구현한 상태는 아니다.

캡처만으로 검색 유입이나 문의 성과를 판단하지 않았다. 기사 원문과 문장별로 대조하지 않았으므로 기사 전체를 그대로 전재했다고 분류하지 않았다. 경쟁사의 수치·성과를 유라클 실적으로 사용하지 않는다.
